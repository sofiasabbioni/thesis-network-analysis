# Exported correlation networks

Node and edge lists for the two networks, so that the networks themselves — not
only the statistics computed from them — can be reused directly from this
repository. Unlike `data/` and `outputs/`, this folder is tracked by git.

Both networks use identical column names, so anything that reads one reads the
other. They are kept apart by file name and are **never merged**: they cover
different universes, different sector taxonomies and different numbers of
stocks.

## Files

| File | Network | Status |
|---|---|---|
| `network_nodes_threshold_0_5.csv` | Original 47-stock thesis network, τ = 0.5 | present |
| `network_edges_threshold_0_5.csv` | " | present |
| `large_network_nodes_threshold_0_5.csv` | Large 503-constituent network, τ = 0.5 | generated by the first extension run |
| `large_network_edges_threshold_0_5.csv` | " | " |

## Columns

**Nodes** — `ticker`, `company`, `sector`, `degree`, `component`,
`is_isolated`, `is_articulation_point`, `network_role`, `is_mst_leaf`

`component` is 0 for the giant component and increases with decreasing size.
Isolated nodes **are** included: a stock with no edge at τ = 0.5 is a result of
the analysis, not a row to drop.

**Edges** — `source`, `target`, `correlation`, `abs_correlation`,
`mantegna_distance`, `same_sector`

One row per undirected edge, with `source` ≤ `target` alphabetically and rows
sorted by descending `abs_correlation`, so the files are byte-reproducible.
`mantegna_distance` is d_ij = √(2(1 − C_ij)).

## Sector labels differ between the two networks

The thesis network uses the 10 informal sector labels of `config.STOCKS`
(`Technology`, `Healthcare`, …). The large network uses the 11 official GICS
sector names (`Information Technology`, `Health Care`, …, plus `Materials`).
Do not join the two files on `sector`.

## Regenerating

```bash
python export_thesis_network.py          # the 47-stock files
python large_network_extension.py --refresh   # the large-network files
```

`export_thesis_network.py` rebuilds the graph from
`outputs/tables/correlation_matrix.csv` with the same `src/graph_construction`
code the thesis pipeline used, and cross-checks the result against the original
run's tables before writing. It downloads nothing and writes nothing into
`data/` or `outputs/`.
